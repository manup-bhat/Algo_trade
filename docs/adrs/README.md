# Architecture Decision Records (ADRs)

This directory contains the foundational Architecture Decision Records for the OpenAlgo trading platform. These documents record the context and consequences of the major design decisions made to guarantee future-proof extensibility and structural safety as the platform transitions to a multi-strategy, agent-driven environment.
